# 账号锁定与解锁自助指南

- 文档编号：XQ-IT-2026-045
- 版本号：V2.5
- 生效日期：2026-08-01
- 适用范围：办公应用系统账号（工单系统、协同盘、审批中心）
- 责任部门：信息技术部 服务台与终端组
- 服务台：分机 6001

## 一、适用范围说明

本指南只处理**办公应用系统账号**的锁定问题，包括星桥 IT 工单、协同盘、审批中心等系统。域账号、VPN、邮箱、无线网络的锁定规则不同，请分别查阅对应文档，切勿套用本指南的数值。

## 二、锁定规则

1. 连续 3 次输入错误密码，办公应用系统账号将被锁定。
2. 该类账号的锁定**不设自动解锁时长**，必须由人工处理。
3. 解锁需要直属主管在工单中确认申请人为本人且无异常，再由服务台执行解锁。
4. 解锁操作完成后，权限在 5 分钟内恢复。

## 三、自助排查步骤（解锁前请先确认原因）

1. 确认大小写锁定键状态与输入法是否为英文半角。
2. 确认是否近期修改过密码，可能是旧密码残留导致连续失败。
3. 确认是否有他人使用过你的账号（如在会议室电脑上保存过凭据）。
4. 打开星桥 IT 工单，查看是否有「账号安全提醒」通知。
5. 若确认密码正确仍失败，说明可能是密码已过期，请走《密码找回与重置流程 FAQ》。

## 四、申请解锁流程

1. 在星桥 IT 工单选择「应用系统账号解锁」。
2. 填写账号、所属部门、锁定时间、已尝试步骤。
3. 直属主管审批确认。
4. 服务台执行解锁，处理时限 4 小时。
5. 解锁后请立即登录一次，确认可以正常使用。

## 五、时限与阈值汇总

| 事项 | 阈值或时限 |
| --- | --- |
| 触发锁定的失败次数 | 连续 3 次 |
| 自动解锁 | 不提供 |
| 主管审批时限 | 1 个工作日 |
| 服务台解锁处理 | 4 小时 |
| 解锁后权限恢复 | 5 分钟内 |
| 同一账号每月解锁次数上限 | 4 次 |

同一账号每月解锁超过 4 次的，服务台将转信息安全组核查是否为异常登录。

## 六、异常与例外情况

1. **忘记主管联系方式**：可先提交工单，由服务台协助联系所属部门。
2. **主管出差无法审批**：由部门内代行职责的负责人审批，需在工单中注明。
3. **怀疑账号被盗用**：不要走普通解锁流程，直接致电分机 6001 声明「安全事件」，按《信息安全事件分级与上报流程》处理。
4. **外包人员账号锁定**：由项目负责人审批，信息安全组复核。

## 七、常见问题

- **等 15 分钟能自动解锁吗？** 不能，这是应用系统账号，与域账号的 15 分钟自动解锁完全不同。
- **怎么总是我锁定？** 常见原因是多台设备保存了旧密码，建议清理已保存的凭据。
- **解锁后多久能用？** 通常 5 分钟内。
- **每月可以解锁几次？** 常规 4 次，超出会触发安全核查。

## 八、联系方式

- IT 服务台：分机 6001（工作日 09:00–18:30）
- 工单入口：it.xingqiao.local，类型选择「账号与权限」
- 服务邮箱：it-help@xingqiao.local

## 九、解锁后的必要动作

1. 登录一次并确认功能正常，如有异常在 1 小时内反馈工单。
2. 检查并清理所有已保存凭据的设备与应用，避免再次触发锁定。
3. 若怀疑密码已泄露，立即走《密码找回与重置流程 FAQ》重置密码，并同步更新令牌绑定。
4. 在 3 个工作日内确认个人资料与联系方式是否为最新。

## 十、安全审计与观察名单

| 情形 | 处理 |
| --- | --- |
| 单月解锁 1–3 次 | 正常，服务台直接处理 |
| 单月解锁 4 次 | 服务台提示并记录 |
| 单月解锁超过 4 次 | 转信息安全组核查登录来源 |
| 出现异地登录记录 | 按安全事件上报，可能冻结账号 |
| 涉及共享账号迹象 | 通报所在部门并整改 |

审计记录留存 180 天。

## 十一、与其他文档的边界

- 域账号锁定（连续 6 次、15 分钟自动解锁）见《域账号锁定与解锁自助指南》；
- 域账号、VPN、邮箱、无线的阈值各不相同，汇总表见《密码复杂度与锁定策略规范》；
- 密码过期导致无法登录，见《密码找回与重置流程 FAQ》；
- 账号被停用（90 天未登录）不是锁定，需主管确认后恢复。

## 十二、常见问题补充

- **能自己解锁吗？** 不能，应用系统账号锁必须由主管确认后人工解锁。
- **解锁要收费吗？** 不收费，也不计入个人考核。
- **周末能解锁吗？** 需在工作日办理，紧急情况可致电分机 6001 升级。
- **锁定期间能提交工单吗？** 可以，工单系统登录页提供「无账号提交」入口。
