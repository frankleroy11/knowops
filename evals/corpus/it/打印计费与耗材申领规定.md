# 打印计费与耗材申领规定

- 文档编号：XQ-IT-2026-040
- 版本号：V2.4
- 生效日期：2026-07-10
- 适用范围：全体职工及外包驻场人员
- 责任部门：供应链与行政部
- 技术支持部门：信息技术部 服务台与终端组
- 服务台：分机 6001

## 一、计费标准

为控制打印成本、倡导无纸化办公，星桥科技对办公区打印实行计费管理。

| 打印类型 | 计费单价 | 说明 |
| --- | --- | --- |
| 黑白单面 | 0.05 元/页 | 默认模式 |
| 黑白双面 | 0.08 元/页 | 按张计费 |
| 彩色单面 | 0.35 元/页 | 需手动选择 |
| 彩色双面 | 0.60 元/页 | 需手动选择 |
| A3 纸张 | 在上述单价基础上加 0.10 元/页 | 需提前申领纸张 |

## 二、免费额度与结算

1. 每人每月免费额度 200 页，按黑白单面折算。
2. 超出部分按部门成本中心结算，不计入个人工资扣除。
3. 每月 1 日额度重置，不累计、不结转。
4. 用量明细可在星桥打印客户端中查询，保留 12 个月。
5. 个人月度用量超过 1000 页时，行政部将回访确认业务用途。

## 三、耗材申领

1. 纸张、硒鼓、墨盒由供应链与行政部统一采购与发放。
2. 申领需提前 1 个工作日提交，通过星桥 IT 工单「耗材申领」。
3. 单个部门每月硒鼓申领上限 4 支，超出需说明原因。
4. 硒鼓回收由行政部统一处理，不得自行丢弃。

## 四、时限与阈值汇总

- 免费额度：每月 200 页；
- 额度重置：每月 1 日；
- 用量明细保留：12 个月；
- 高用量回访阈值：1000 页/月；
- 耗材申领提前量：1 个工作日；
- 部门硒鼓月度上限：4 支。

## 五、旧版制度说明

原《打印耗材领用细则（2022）》规定「不设免费额度、彩色打印 0.20 元/页、硒鼓按需无限申领」，该口径已不再执行。其废止声明为「本制度自 2024 年 12 月废止，以《打印计费与耗材申领规定》为准」。凡涉及单价与额度的问题，一律按本规定答复。

## 六、异常与例外情况

1. **投标与审计等特殊任务**：可申请临时额度，需部门负责人确认，单次最多 500 页。
2. **设备故障导致重复打印**：经核实后冲减用量，需在 3 个工作日内提交工单。
3. **异地办公**：上海分部执行同一计费标准，额度按账号归集。
4. **外包驻场人员**：免费额度为每月 50 页，由其项目负责人管理。

## 七、常见问题

- **打印了没取会退钱吗？** 不退。任务保留 2 小时，超时自动清除仍计费。
- **怎么知道还剩多少额度？** 在打印客户端首页查看。
- **耗材能自己买吗？** 不能，须走统一采购渠道以保证设备保修。
- **彩色打印为什么贵？** 彩色耗材成本显著更高，建议仅在必要时使用。

## 九、用量查询与争议处理

1. 用量可在星桥打印客户端「我的用量」中查询，支持按日、按周、按月查看。
2. 对用量有异议的，请在 3 个工作日内提交工单，行政部在 2 个工作日内完成核查。
3. 因设备故障导致的重复打印，核查后予以冲减。
4. 打印任务保留 2 小时，超时未取仍计费，不作为冲减理由。

## 十、部门成本分摊

| 部门 | 结算方式 | 月度对账时间 | 说明 |
| --- | --- | --- | --- |
| 产品研发中心 | 按成本中心分摊 | 次月 3 日前 | 用量最大的部门 |
| 市场与客户成功部 | 按成本中心分摊 | 次月 3 日前 | 彩色打印占比高 |
| 财务部 | 按成本中心分摊 | 次月 3 日前 | 单据打印集中 |
| 人力资源部 | 按成本中心分摊 | 次月 3 日前 | 含合同扫描 |
| 其他部门 | 按成本中心分摊 | 次月 3 日前 | 统一口径 |

超出免费额度的部分计入部门办公成本，不涉及个人薪酬扣减。

## 十一、无纸化倡导指标

- 部门双面打印比例目标：不低于 60%；
- 部门黑白打印比例目标：不低于 85%；
- 月度人均打印量目标：不高于 120 页；
- 达成情况按季度在部门例会上通报。
