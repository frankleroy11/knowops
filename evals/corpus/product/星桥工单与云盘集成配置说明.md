# 星桥工单与云盘集成配置说明

- 文档编号：XQ-TICKET-INT-108
- 文档版本：v1.9
- 发布日期：2026-08-02
- 适用产品版本：星桥工单 4.2.x、星桥云盘 3.4.x
- 维护部门：星桥科技解决方案组

## 1. 集成价值

星桥工单与星桥云盘打通后，工单可以引用云盘文件而不是把大附件塞进工单；处理人可以直接在工单中预览日志、截图与诊断包；工单关闭后引用关系仍然保留，便于追溯。集成基于统一账号，不需要额外的账号映射，但需要开启对应开关并配置权限。

## 2. 前置条件

| 条件 | 要求 |
| --- | --- |
| 工单版本 | 4.1.0 及以上 |
| 云盘版本 | 3.2.0 及以上 |
| 云盘集成插件 | 1.4.0 及以上 |
| 统一账号 | 已开启且两端同一租户 |
| 权限 | 工单侧 `ticket.read`，云盘侧 `drive.read` |
| 网络 | 双向可达，回调使用 443 端口 |

插件低于 1.4.0 时，附件预览会返回空白页，请在控制台"应用市场—已安装"中确认版本。

## 3. 配置步骤

1. 在工单控制台"集成—云盘"中开启集成开关。
2. 选择允许引用的云盘空间，最多 20 个。未选中的空间无法被工单引用。
3. 配置引用权限：可选"仅提交人可见"或"处理人可见"。选择"仅提交人可见"时，处理人需要提交人单独授权才能打开文件。
4. 配置回调地址，用于云盘文件变更时同步工单状态。回调使用 HTTPS，端口固定 443。
5. 点击"连通性测试"，五项检查全部通过后保存。

## 4. 引用方式

工单中引用云盘文件有三种方式：

| 方式 | 操作 | 是否需要云盘权限 |
| --- | --- | --- |
| 粘贴云盘分享链接 | 在描述中粘贴链接，系统自动识别 | 需要，按链接权限 |
| 从云盘选择器插入 | 点击"插入云盘文件"选择 | 需要 |
| 由自动化规则附加 | 在自动化中配置固定目录 | 需要 |

系统自动识别链接时，会校验链接是否属于本租户且空间在允许列表内。跨租户链接不会被识别，只会作为普通文本保留。

## 5. 权限与安全

引用不会改变云盘侧原有的权限设置。若文件所在空间未对处理人开放，处理人打开链接会看到 403。建议在提交流程中提示用户：需要支持人员查看的文件，请把支持人员加入临时协作或改为"处理人可见"。

集成不会把云盘文件复制到工单系统，工单只保存对象 ID 与版本号。云盘侧文件被删除后，工单中的引用显示"文件已删除"，引用记录本身仍保留 180 天。

## 6. 同步规则

| 云盘事件 | 工单侧动作 |
| --- | --- |
| 文件产生新版本 | 工单时间线追加版本变更记录 |
| 文件被删除 | 引用标记为失效，通知工单处理人 |
| 文件恢复 | 引用恢复可用 |
| 外链被关闭 | 引用仍可用（引用走内部权限，不依赖外链） |

同步存在最长 60 秒的延迟，属于设计行为。若需要实时性更高的场景，请直接使用云盘 Webhook。

## 7. 常见问题排查

**问题一：插入云盘文件时列表为空。**
检查工单侧账号是否与云盘账号一致，以及当前空间是否在允许引用列表中。

**问题二：处理人打不开引用文件。**
按第 5 节的权限说明处理。这是权限问题，不是集成故障。

**问题三：连通性测试第 3 项失败。**
第 3 项测试的是双向回调，失败通常是防火墙未放通 443 端口出站，或回调地址无法从云盘侧解析。

**问题四：时间线里出现重复的版本变更记录。**
云盘回调存在重复投递（重复率约 0.3%），集成插件按投递 ID 去重，若插件版本低于 1.4.0 则不会去重，请升级插件。

## 8. 停用集成

停用集成后，已有引用记录保留但不再同步，新引用无法创建。停用不会删除云盘文件。若要彻底清理引用关系，需在工单侧执行"清理集成数据"，该操作不可逆，耗时约为每 10 万条引用 5 分钟。

## 9. 性能与容量

集成对云盘接口的调用受云盘限流约束：每令牌每分钟 600 次。若工单量大（日均 5000 条以上）且每条都引用文件，建议把集成插件部署为独立应用，避免与其它集成共享令牌额度。

## 10. 配置项速查

| 配置项 | 默认值 | 可调范围 | 说明 |
| --- | --- | --- | --- |
| 集成开关 | 关闭 | 开/关 | 需管理员权限 |
| 允许引用的空间数 | 0 | 最多 20 个 | 未选中的空间不可引用 |
| 引用权限 | 仅提交人可见 | 仅提交人/处理人可见 | 影响处理人能否直接打开 |
| 回调端口 | 443 | 固定 | 仅支持 HTTPS |
| 单向文件大小 | 无限制 | 固定 | 引用不复制文件 |
| 同步延迟 | 最长 60 秒 | 固定 | 属设计行为 |
| 引用记录保留 | 180 天 | 固定 | 文件删除后引用记录仍在 |

## 11. 集成健康度监控

建议开启三项监控：回调成功率（低于 95% 告警）、引用打开失败率（高于 5% 告警）、同步延迟（持续超过 120 秒告警）。三项指标可在控制台"集成—健康度"中查看，历史数据保留 90 天。

若引用打开失败率突然升高，最常见的根因是空间权限被批量调整，而不是集成故障。请先核对近期是否有权限变更操作，再检查插件版本。

## 12. 卸载与数据清理

卸载集成插件前，请先关闭集成开关，避免回调积压。关闭后已有引用变为只读，仍可查看但不能新增。清理集成数据会删除引用关系但不会删除云盘文件，该操作不可逆，建议先导出引用清单留存。

清理耗时参考：每 10 万条引用约 5 分钟，超过 100 万条引用时建议在非工作时间执行，并提前通知用户。
