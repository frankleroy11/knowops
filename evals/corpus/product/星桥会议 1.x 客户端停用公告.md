# 星桥会议 1.x 客户端停用公告

- 文档编号：XQ-MEET-EOL-207
- 文档版本：v1.3
- 发布日期：2026-04-20
- 适用产品版本：星桥会议 2.0 及以上
- 维护部门：星桥科技会议研发组

## 1. 公告要点

星桥会议 1.x 桌面客户端自 v2.0 起已停用，请改用 2.x 客户端。停用后 1.x 客户端无法登录，界面会提示"版本过低，请升级后使用"，且不再收到任何功能更新与安全修复。本公告给出停用范围、时间线、替代方案与迁移指引。

## 2. 停用范围

| 组件 | 是否停用 | 说明 |
| --- | --- | --- |
| 1.x 桌面客户端（全部平台） | 是 | 无法登录 |
| 1.x 移动端 | 是 | 无法登录，应用商店已下架 |
| 1.x 会议室连接器 | 是 | 需升级到 1.6.0 以上 |
| 旧接口 `room.create` | 废弃（自 v2.5 起） | 仍可调用，返回兼容性告警 |
| Web 入会页 | 否 | 随服务端发布，无需升级 |

旧接口 `room.create` 自 v2.5 起废弃，请改用 `rooms.create`（REST 路径 `POST /api/v2/rooms`）。两者返回的字段结构不同，旧接口的 `participants` 字段为字符串数组，新接口为对象数组并附带权限字段。

## 3. 时间线

| 时间 | 事件 |
| --- | --- |
| 2026-02-01 | 停止 1.x 功能更新 |
| 2026-04-01 | 1.x 客户端停止新下载，应用商店下架 |
| 2026-04-20 | 发布本停用公告，进入 90 天过渡期 |
| 2026-07-19 | 过渡期结束，1.x 客户端无法登录 |
| 2026-10-31 | 旧接口 `room.create` 计划停止服务 |

过渡期内 1.x 客户端仍可登录，但会每天弹出一次升级提醒。过渡期结束后服务端直接拒绝 1.x 的登录请求。

## 4. 停用原因

1.x 客户端使用的编解码协商机制与新版本不兼容，导致 1.x 与 2.x 客户端互连时约 8% 的会议出现单向音频。该问题无法在 1.x 侧修复，只能通过升级解决。此外 1.x 不支持等候室、实时字幕与本地模式。

## 5. 替代与升级路径

| 原用途 | 替代方案 |
| --- | --- |
| 桌面开会 | 升级到 2.x 桌面客户端 |
| 免安装参会 | 使用 Web 入会页 |
| 会议室硬件 | 升级连接器到 1.6.0 以上 |
| 1.x 的接口集成 | 迁移到 `rooms.create` |
| 1.x 的本地录制 | 使用云端录制（标准版以上） |

批量升级建议使用企业软件分发工具，2.x 客户端支持静默安装参数 `--silent` 与 `--keep-account`，后者可保留原登录账号，减少用户操作。

## 6. 迁移检查清单

- [ ] 统计仍在运行的 1.x 终端数量，逐台登记。
- [ ] 确认会议室连接器版本不低于 1.6.0。
- [ ] 更新防火墙规则，放通 TCP 443、TCP 8443 与 UDP 50000 至 50100。
- [ ] 把接口集成从 `room.create` 迁移到 `rooms.create`。
- [ ] 通知用户升级，并说明升级后需要重新登录一次。
- [ ] 对无法升级的老旧设备准备替代方案（如 Web 入会页）。

## 7. 无法升级设备怎么办

部分老旧终端操作系统版本过低，无法安装 2.x 客户端。建议改用 Web 入会页参会；若必须使用会议室硬件，可部署一台中间终端运行 Web 入会页并外接摄像头与麦克风。Web 入会页的功能限制为：不支持共享屏幕、录制、虚拟背景与实时字幕。

## 8. 常见问题

**问：不升级会怎样？**
过渡期结束后无法登录，且不会收到安全修复。

**问：升级后历史会议记录会丢吗？**
不会。会议记录保存在服务端，与客户端版本无关。

**问：旧接口还能继续用多久？**
`room.create` 自 v2.5 起废弃，计划 2026-10-31 停止服务，建议在过渡期内完成迁移。

**问：1.x 的本地录制文件怎么办？**
本地文件不受影响，仍在原目录。迁移后可上传到云盘统一管理。

## 9. 客服应答话术要点

面向仍在用 1.x 的客户，回答时把握三个要点，避免引发不必要的争议：

1. **明确结论**：1.x 客户端自 v2.0 起已停用，2026-07-19 过渡期结束后无法登录，这不是本次故障造成的，而是既定版本策略。
2. **给出路径**：桌面场景升级到 2.x 客户端（支持静默安装并保留账号）；免安装场景用 Web 入会页；会议室硬件升级连接器到 1.6.0 以上。
3. **说明差异**：Web 入会页不支持共享屏幕、录制、虚拟背景与实时字幕，若客户依赖这些能力，必须升级桌面客户端。

若客户设备无法安装 2.x 客户端，请登记设备信息并升级工单给交付团队评估替代方案，不要承诺"可以继续用 1.x 登录"。
