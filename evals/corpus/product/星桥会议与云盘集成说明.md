# 星桥会议与云盘集成说明

- 文档编号：XQ-MEET-INT-208
- 文档版本：v1.7
- 发布日期：2026-08-11
- 适用产品版本：星桥会议 2.8.x、星桥云盘 3.4.x
- 维护部门：星桥科技解决方案组

## 1. 集成内容

星桥会议与星桥云盘的集成覆盖四个场景：会前共享材料、会中共享云盘文件、会后录制自动归档、纪要自动生成文档。集成基于统一账号，默认开启，无需额外授权，但管理员可以按空间粒度限制共享范围。

## 2. 场景一：会前共享材料

预约会议时可添加云盘文件作为会议材料。材料会出现在会议详情的"材料"区域，参会人点击即可用云盘权限访问，会议不会复制文件。若参会人没有该文件的访问权限，看到的是申请访问入口而不是错误页。

材料数量上限为 50 个，单文件不超过 2 GB。超过 2 GB 的文件建议在会中通过共享屏幕方式展示。

## 3. 场景二：会中共享云盘文件

会中可通过"共享—云盘文件"选择文件进行共享。共享过程只传输渲染后的画面，不改变云盘权限。会议结束后，共享记录会写入会议时间线，但不写入云盘审计日志（因为未发生下载动作）。

需要注意：如果共享的是需要保密的文件，建议先开启"仅共享选定窗口"，避免桌面其它内容被看到。旗舰版可开启禁止截屏，但该能力仅对桌面客户端生效。

## 4. 场景三：录制自动归档

录制文件生成后自动上传至云盘"会议录制"空间，目录结构为：年份/月份/会议标题-会议编号/。上传完成时间通常为会议结束后 3 到 10 分钟。

| 项目 | 说明 |
| --- | --- |
| 存储位置 | 云盘"会议录制"空间 |
| 目录规则 | 年/月/会议标题-会议编号 |
| 占用的配额 | 云盘存储配额 |
| 默认保留期 | 标准版 90 天，旗舰版 180 天 |
| 可选格式 | MP4（H.264 + AAC） |
| 单文件上限 | 8 小时录制时长 |

录制文件在会议侧保留期到期后会移入云盘回收站，再按云盘规则保留 30 天。完整口径见《星桥会议录制与存储保留策略》。

## 5. 场景四：纪要生成文档

旗舰版与标准版支持纪要生成。纪要在会议结束后约 15 分钟生成，可一键保存为云盘文档，格式支持在线文档与 Markdown。保存后文档归入"会议纪要"目录，权限继承会议主持人所在空间。

纪要支持人工编辑，编辑记录不保留版本历史以外的额外痕迹。若需要留痕，建议保存后开启该空间的版本保留策略。

## 6. 权限模型

| 角色 | 查看材料 | 下载录制 | 编辑纪要 | 修改归档目录 |
| --- | --- | --- | --- | --- |
| 会议主持人 | 是 | 是 | 是 | 是 |
| 白名单成员 | 是 | 是 | 是 | 否 |
| 普通参会人 | 按云盘权限 | 否 | 否 | 否 |
| 外部参会人 | 仅共享屏幕可见 | 否 | 否 | 否 |

外部参会人（无账号）无法访问会议材料，只能看到会议中共享的画面。若需要向外部提供材料，请生成外链，并注意外链有效期遵循云盘套餐规则。

## 7. 配置项

| 配置 | 默认值 | 可调范围 | 说明 |
| --- | --- | --- | --- |
| 录制自动归档 | 开启 | 开/关 | 关闭后录制仅保留 7 天 |
| 归档空间 | 会议录制 | 任意允许的空间 | 需有写入权限 |
| 纪要自动保存 | 关闭 | 开/关 | 开启后自动生成文档 |
| 材料数量上限 | 50 个 | 1 至 50 个 | 固定上限 |
| 共享文件大小上限 | 2 GB | 固定 | 超过建议屏幕共享 |
| 归档目录命名规则 | 年/月/标题-编号 | 可自定义模板 | 支持变量 |

## 8. 故障排查

**问题一：会中共享云盘文件时列表为空。**
检查会议账号与云盘账号是否为同一账号，以及管理员是否限制了共享空间范围。

**问题二：录制没有出现在云盘。**
按顺序检查：套餐是否支持录制、归档开关是否开启、归档空间是否还有配额。配额不足时录制仍会生成，但归档会失败并通知主持人。

**问题三：参会人打不开材料。**
材料按云盘权限控制。请把参会人加入材料的可访问范围，或改为生成外链。

**问题四：纪要保存后找不到。**
纪要会保存到主持人所在空间的"会议纪要"目录。若主持人不在任何空间，保存会失败并给出提示。

## 9. 性能与容量规划

一场 1 小时的 720p 会议录制约占 450 MB，1080p 约 900 MB。若企业每日 20 场 1 小时会议且全部录制，月增约 270 GB（720p）。建议按季度评估云盘配额，并考虑把保留期从 180 天下调到 90 天。
