# 星桥云盘 Webhook 事件回调说明

- 文档编号：XQ-DRIVE-HOOK-014
- 文档版本：v2.4
- 发布日期：2026-08-09
- 适用产品版本：星桥云盘 3.4.x
- 维护部门：星桥科技开放平台组

## 1. 概述

Webhook 让星桥云盘在文件或空间发生变化时主动通知接入方，避免轮询。接入方在控制台"开放平台—回调"中登记地址，登记后需要完成一次验证握手才能生效。每个租户最多登记 20 个回调地址，每个地址最多订阅 12 类事件。

## 2. 事件类型

| 事件名 | 触发时机 | 是否可批量 |
| --- | --- | --- |
| `object.created` | 新文件上传完成 | 否 |
| `object.updated` | 文件产生新版本 | 否 |
| `object.deleted` | 文件进入回收站 | 否 |
| `object.restored` | 文件从回收站恢复 | 否 |
| `object.moved` | 文件或目录移动 | 是 |
| `share.created` | 外链创建 | 否 |
| `share.revoked` | 外链被关闭 | 否 |
| `quota.warning` | 用量达到配额 80% 或 95% | 否 |
| `member.changed` | 成员角色变更 | 是 |
| `upload.failed` | 上传会话最终失败 | 是 |

`quota.warning` 事件每天最多发送 3 次，避免用量快速上涨时造成通知风暴。

## 3. 回调地址要求

回调地址必须使用 HTTPS，端口固定 443，不支持自定义端口。地址必须是公网可解析的域名，不接受 IP 直连。接入方需在 3 秒内返回 2xx 状态码，超时即视为失败并进入重试队列。响应体内容不校验，但建议返回 `{"ok":true}` 便于日志比对。

若接入方需要区分环境，请使用两个不同的回调地址，不要用同一地址加参数区分，因为参数在重试时会被原样重放。

## 4. 签名校验

每次回调都会带四个头：`X-XQ-Event`（事件名）、`X-XQ-Delivery`（投递 ID）、`X-XQ-Timestamp`（Unix 秒级时间戳）、`X-XQ-Signature`（签名）。签名算法为：以 `timestamp + "." + 原始请求体` 作为待签内容，用应用密钥做 HMAC 计算，结果为十六进制字符串。

校验要点三条：一是必须用原始请求体参与计算，任何框架的自动 JSON 解析后再序列化都会导致校验失败；二是时间戳容忍窗口为 300 秒，超出直接拒绝；三是签名比对必须使用常量时间比较，避免时序攻击。

## 5. 重试机制

投递失败后按固定序列重试，共 5 次，间隔为 10 秒、30 秒、90 秒、270 秒、810 秒，总跨度约 20 分钟。全部失败后投递记录标记为 `dead`，可在控制台手工重放，重放窗口为 7 天。

以下情况不重试：签名校验被接入方拒绝（返回 401 或 403）、地址返回 404、地址返回 410。这三类被判定为配置错误，需要接入方修正配置后手工重放。

## 6. 幂等与顺序

Webhook 不保证严格顺序。同一文件先产生的 `object.updated` 有可能晚于后产生的 `object.moved` 到达。接入方必须用 `X-XQ-Delivery` 去重，并以事件载荷中的 `version` 与 `occurred_at` 自行排序。

同一事件的重复投递可能发生在网络抖动场景，重复率在生产环境中约为 0.3%。使用 `X-XQ-Delivery` 作为幂等键即可安全处理。

## 7. 载荷示例

```json
{
  "event": "object.created",
  "delivery_id": "dlv_9f2c1a",
  "occurred_at": "2026-08-09T14:22:31+08:00",
  "tenant_id": "T-8801",
  "space_id": "SP-1024",
  "object": {"id": "obj_7712", "path": "/交付/方案.pdf", "size": 104857600, "version": 3}
}
```

载荷中的 `path` 是逻辑路径，不含物理存储位置。`size` 单位为字节。

## 8. 安全与配额

回调请求来自星桥云盘固定出口地址段，接入方可据此做来源白名单，但不得仅依赖来源判定，必须校验签名。回调本身不消耗接口配额，但接入方在处理回调时如果回调调用云盘接口，仍受每令牌每分钟 600 次的限制，超出返回 429。

## 9. 常见问题

**问：为什么我的回调总是校验失败？**
九成原因是框架把请求体重新序列化了。请以原始字节计算签名。

**问：回调能带自定义请求头吗？**
可以，控制台支持配置最多 5 个自定义头，值不可包含换行符。

**问：能只订阅某个目录的事件吗？**
可以，订阅时可指定路径前缀，最多 50 个前缀。

**问：回调失败会通知我吗？**
连续 3 次投递失败后，系统会向应用联系人发送邮件提醒。
