# 星桥工单通知模板与回调配置

- 文档编号：XQ-TICKET-NOTI-109
- 文档版本：v2.0
- 发布日期：2026-08-03
- 适用产品版本：星桥工单 4.2.x
- 维护部门：星桥科技工单研发组

## 1. 通知体系概览

星桥工单的通知由"事件 + 规则 + 模板 + 通道"四部分组成。事件是触发源，规则决定谁在什么条件下收到，模板决定内容，通道决定发送方式。四个部分任意一环配置错误都会导致通知不到，排查时请按此顺序定位。

## 2. 通知事件

| 事件 | 触发时机 | 默认通道 |
| --- | --- | --- |
| `ticket.created` | 工单创建成功 | 邮件 |
| `ticket.assigned` | 工单分派给处理人 | 邮件、站内信 |
| `ticket.replied` | 有新的对外回复 | 邮件 |
| `ticket.escalated` | 工单自动或手工升级 | 邮件、短信 |
| `ticket.sla_warning` | 距响应时限剩余 20% | 站内信、短信 |
| `ticket.closed` | 工单关闭 | 邮件 |
| `ticket.survey` | 满意度调查发出 | 邮件 |

短信通道仅用于 `ticket.escalated` 与 `ticket.sla_warning` 两类事件，标准版每月赠送 500 条短信，旗舰版 5000 条，超出部分按量计费。

## 3. 模板变量

模板支持以下变量，写法为双花括号包裹：

| 变量 | 含义 | 是否可空 |
| --- | --- | --- |
| `{{ticket.id}}` | 工单编号 | 否 |
| `{{ticket.title}}` | 标题 | 否 |
| `{{ticket.priority}}` | 等级 | 否 |
| `{{ticket.status}}` | 状态 | 否 |
| `{{ticket.handler}}` | 处理人显示名 | 是 |
| `{{ticket.link}}` | 工单链接 | 否 |
| `{{custom.xxx}}` | 自定义字段 | 是 |

自定义字段为空是模板渲染失败的首要原因。4.2.1 起渲染失败不再静默丢弃，而是回退到默认模板并记录告警日志。请在模板中对可空变量使用默认值语法。

## 4. 通道配置

| 通道 | 配置项 | 端口 | 备注 |
| --- | --- | --- | --- |
| 邮件 | 发信中继地址、发件人 | 2525 | 需放通出站 2525 |
| 短信 | 签名、模板编号 | 不适用 | 需先完成签名审核 |
| 站内信 | 无需配置 | 不适用 | 默认开启 |
| Webhook | 回调地址 | 443 | 仅支持 HTTPS |

邮件通道使用 2525 端口，这是最常见的配置坑：企业防火墙习惯放通 25 端口，若未放通 2525，会出现"发送状态成功但用户收不到"的假象。请在配置后使用"发送测试通知"功能验证。

## 5. Webhook 回调配置

回调地址必须为 HTTPS，端口固定 443。每次回调携带四个头：`X-XQ-Event`、`X-XQ-Delivery`、`X-XQ-Timestamp`、`X-XQ-Signature`。签名内容为 `timestamp + "." + 原始请求体`，算法与云盘一致，时间戳容忍 300 秒。

失败重试 4 次，间隔为 30 秒、2 分钟、10 分钟、30 分钟。全部失败后标记为 `dead`，可在控制台手工重放，重放窗口 7 天。回调返回 401、403、404、410 时不重试，视为配置错误。

## 6. 去重与顺序

Webhook 不保证顺序。同一工单的分派事件可能晚于回复事件到达。请以 `X-XQ-Delivery` 去重，并按载荷中的 `occurred_at` 排序。重复投递在生产环境中约占 0.3%。

## 7. 通知风暴保护

为避免一个批量操作触发上千条通知，系统内置三项保护：同一工单 60 秒内最多发送 3 条通知；同一收件人 60 秒内最多收到 20 条；批量操作合并为一条汇总通知。若确需逐条通知，可在规则中关闭合并，但不建议这样做。

## 8. 排查清单

1. 规则是否启用，条件是否过窄（例如只匹配 P0）。
2. 模板变量是否为空，渲染是否失败。
3. 通道配置是否正确，端口 2525 是否放通。
4. 发送日志中的状态是 `sent`、`bounced` 还是 `rate_limited`。
5. 收件人是否被列入退订名单。
6. 是否触发了通知风暴保护。

## 9. 常见问题

**问：能对同一个人发不同模板吗？**
可以。规则中按角色区分模板，例如处理人收到含处理建议的模板，提交人收到不含内部信息的模板。

**问：通知会包含附件吗？**
不会。邮件通知只包含链接，附件需登录后查看。

**问：短信能自定义内容吗？**
可以，但需使用已审核的模板编号，自定义内容仅支持变量替换。

**问：Webhook 能测通再启用吗？**
可以。控制台提供"发送测试事件"，测试事件不消耗配额。
