# Reranker dev 集对照实验

## 实验设置

73 道 dev 题；62 道实际有答案题、11 道隔离题。未调用 Qwen，也未运行 test 集。
BAAI/bge-reranker-base，MPS，max_length=512，batch_size=4。每题只检索一次前 10 条，三种方案共享同一候选集。
原 COSINE 分数保留，重排分数单列。模型初始化和一次暖机单独记录；首批不同长度的 MPS 计算仍可能影响稳态耗时。
本次是开发集探索，非盲测结论。原问答默认流程仍为 dense 检索。

## 决策

普通重排没有提升完整证据覆盖；多样性软限制后的覆盖率与 dense 基线持平，仍增加计算耗时。
因此暂不改默认问答链路，也不宣称此次优化成功。保留可选接口和实验脚本。
首条完整证据覆盖率提高说明排序有局部收益，但整体证据覆盖与首条排序是不同目标。
下一步先分析退化题是否因 512-token 截断、同文档重复或相关性判断导致，确认后再选择实验；
不能仅根据这次结果断言某个因素就是原因。后续最终验证应另留新盲测集。
未进行生成实验，无法推断回答正确率、拒答率或 Qwen 输出质量变化。
11 道隔离题仅校验检索文档所属库，不等同于语义拒答；三种方案均未检出跨库文档。
接口另需验证真实模型调用；单元测试覆盖排序、候选边界、文档软限制和过滤先于重排。
