# 2026-10-16 本地演示版交付与验收

本轮包含检索模块中文注释、可选明文密码演示模式，以及真实账号和新知识库验收。验收以合成数据在本机运行，不代表生产部署或独立盲测。

## 账号与密码

- 本机启用 `PASSWORD_STORAGE=plaintext`；仓库 `.env.example` 默认仍为 `scrypt`。
- 新账号、管理员重置和自助改密可在数据库中看到 `plaintext$原密码`。该标记不是加密，密码及历史记录可能直接被数据库或备份持有者读取。
- 原有摘要不可逆；只有成功通过密码及二次验证才转换，错误登录不改写凭据。切回 scrypt 后也在成功登录或改密时转换。已有历史记录不自动重写。
- 明文演示模式最多 245 字符，以便连同 10 字符标记存入现有 VARCHAR(255)。更长的历史摘要保留原格式，仍可验证。
- 真实 MySQL 验收覆盖公开注册独立租户、跨租户隔离、成员角色／禁用／重启用、管理员重置、自助改密、令牌撤销、搜索分页和自身管理员保护，共 4 组通过。临时账号、凭据文件及对应数据已清理。
- 已使用本地凭据文件成功登录现有账号，确认数据库转换为明文，并登出此次测试会话；这会有意增加正常登录／登出审计和撤销令牌记录，不宣称全部表仍保持原数量。现有浏览器会话未被主动退出。

## 演示与面试顺序

1. 从 [架构图](architecture.md) 说明 Vue、API、SQL、任务队列、Worker、Milvus 与 Qwen 的职责。
2. 登录管理员，创建知识库并上传一份 TXT／Markdown，展示解析状态和索引状态的区别。
3. 在统一问答窗口提问，查看原文引用；再问资料外问题，展示拒答。
4. 用另一租户账号说明数据隔离，展示成员权限与版本审核，而非只演示隐藏按钮。
5. 展示本报告的失败案例和原始记录，说明引用逐字匹配不等于语义支持。
