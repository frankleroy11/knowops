# 审计日志按租户分区 + 前端租户管理

接续 [P3a 多租户](authorization-p3a.md) 中"审计仅平台管理员可读"的临时折中，本阶段把审计真正按租户分区。

## 1. 交付内容

| 文件 | 作用 |
|---|---|
| `app/modules/audit/models.py` | `audit_logs.tenant_id`（可空，平台级记录为 NULL） |
| `app/modules/audit/service.py` | `record()` **按对象反查租户**（知识库/文档/版本/用户/租户），并支持显式覆盖；`list_entries(tenant_id=...)` |
| `app/modules/audit/router.py` | 平台管理员看全部（可按 `tenant_id` 过滤）；租户管理员只看本租户；跨租户过滤 → 403；非管理员 → 403 |
| `migrations/versions/0009_audit_tenancy.py` | 新增列 + 外键 + 索引，历史行按操作者租户回填 |
| `frontend/src/App.vue` | 审计入口对租户管理员重新开放、审计表显示租户列、平台管理员可按租户筛选；用户管理新增「租户」列与租户创建区 |

## 2. 关键语义

- **记录归属看对象，不看操作者**：平台管理员在租户 2 建库，产生的是 `tenant_id=2` 的记录，
  租户 2 的管理员能看到"谁在我的租户里动了什么"；操作者身份仍以文本快照保存。
- **平台级记录 `tenant_id=NULL`**：如创建平台账号、签发平台 Token、创建租户本身（归入新租户）。
  租户管理员看不到这些，平台管理员全部可见。
- 租户管理员不能通过 `?tenant_id=` 读取其他租户（403），也不能看到平台级记录。
