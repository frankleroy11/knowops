没有覆盖恢复当前业务库，也没有演练全量 Milvus 重建；runbook 给出离线重建前置条件。生产恢复必须在单独维护窗口验证，不能把 MySQL/文件演练当作全部系统灾备完成。

## 本地检查与已知边界

246 项后端测试、18 项前端测试、Ruff、前端构建、pip check 和 Alembic 0011 检查通过。页面验证失败列表、定位资料、版本历史和失败版本不可切换；强制认证后的未登录页、管理员实际登录与只读用户无控制台入口也已检查；审计 CSV 在浏览器实际下载成功。单元测试隔离本地 .env 的认证模式。数据库/向量/文件真实清理见集成脚本。

没有自动卡死租约回收、跨系统删除事务、消息 outbox、扫描 PDF OCR、生产邮件发送或公网部署。上传默认审核通过时会先选中新版本、等待处理完成后才能检索；若要求新版本未就绪期间旧版持续服务，还需将自动发布改为索引完成后的原子切换。当前界面已避免将失败版本显示成可检索的已发布资料。
