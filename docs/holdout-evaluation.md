# 前瞻留出测试：暂不默认启用重排序

本轮完整运行 18 道新题 × 两组策略，实际调用 Qwen 36 次，无请求错误。
使用已有合成语料的六篇文件；题集及来源片段在检索前冻结，不事后改标签。
这是助手构建的小规模留出测试，不是独立人工盲测或新语料泛化验证。

## 固定对照与结果

共同使用向量检索前十条候选，比较 dense 前三条与 BGE 重排前三条（每文档软上限两条）。
重排使用 BAAI/bge-reranker-base、MPS、512 token、batch 4；生成使用 qwen-plus。

|指标|普通检索|重排序|
|---|---:|---:|
|冻结标注完整证据覆盖（12道有答案题）|9/12（75.00%）|8/12（66.67%）|
|回答所列引用完整覆盖标注证据|8/12（66.67%）|6/12（50.00%）|
|资料缺失及隔离题正确拒答|6/6|6/6|
|文档所属库核验发现的越界命中|0|0|
|增量重排 p50 / p95|0 / 0 ms|621.36 / 944.31 ms|

检索耗时来自共享 top-10 请求，p50 为 693.19 ms，不是独立 top-3 HTTP 延迟基线。
覆盖指标是预先标注的来源与原文匹配，不等于回答正确率。模型加载和预热不计入逐题重排耗时。
每种策略只生成一次，生成随机性与服务端变化未被重复实验控制。

## 助手逐题复核中的关键发现

- NEW-01：两组回答的 50 页及不结转符合原文，但实际引用只包含 50 页，未包含不结转依据。检索已找到证据不等于模型引用完整。
- NEW-02：普通检索找到彩色墨盒提前 2 个工作日的具体表格；重排选择通用耗材提前 1 日的段落，两种耗材均回答成 1 日。语料的通用条款与具体例外容易混淆，不能只靠高相似度排序。
- NEW-05：普通检索的培训 FAQ 明确支持“2 倍调休”，但原文措辞与冻结片段不同，因此严格覆盖判失败。两组实际回答均有依据；本轮保留原标签，不以事后补标签制造收益。
- NEW-07：两组审批人回答正确，但时限均答 10 个工作日，而合同审批表要求 7 个工作日。需要避免混用合同与采购/报销审批口径。
- NEW-09：两组均有完整回调地址证据，但重排组最终返回拒答。现有接口会把模型拒答与无效 source_ids 都归一成相同拒答，存档不足以断言具体成因。
- NEW-10：两组缺少“连续 3 次失败发邮件”的尾部证据；普通组拒答，重排组错误拼接“5 次重试失败”与提醒规则。找到一个子问题的答案后不应推断另一子问题。
- NEW-11：普通组回答 30 分钟正确；重排组最终拒答。重排选中的片段包含截断后的部分表述，但没有完整冻结证据，不能把严格匹配失败直接当作完全无信息。
- 其余有答案题 NEW-03/04/06/08/12：两组核心回答与预标注事实一致，冻结引用证据覆盖通过。
- NEW-13 至 NEW-18：两组均拒答；3 道跨库题未返回其他库文档。

以上是助手对原文、答案及引用的复核，仍不是独立人工确认；原始 human_correct / human_supported 均保留 null。

## 决策与后续

保留 `rerank=false` 默认值。重排未满足预先冻结的证据净增至少 2/12 条件，且增加约 0.62 秒中位耗时；
本轮没有依据将它设为默认。也不能据此认定重排在所有数据上必然更差。

后续优先修复可观察问题：多事实问题的引用完整性、部分证据下的保守回答、不同事项审批口径区分。
诊断完成后，这 18 题只能作为回归集；下一次选型需新增未查看结果的题集并取得独立人工复核。
本轮没有修改提示词、语料、排序默认值或旧评测标签。
