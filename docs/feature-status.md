# 功能状态与本轮完善（2026-10-16）

以当前代码为准。其他按日期记录的验收文档描述当时状态，其中“未实现”不一定仍适用于今天。

## 已有功能

- 公开注册独立空间、密码/Token 登录、管理员与普通用户页面、多租户和知识库成员权限。
- TXT、Markdown、文本 PDF 上传；Celery 异步解析、切分、BGE-M3 向量化、Milvus 检索。
- 文档版本、审核发布、删除、失败重试、成员管理及审计。
- MySQL 标准问答优先匹配、Redis 成功答案缓存、未命中进入带来源引用的 RAG。
- 单库和统一问答、可选相邻片段补充、答案反馈、会话按检索范围保存。
- 原创青岚知识库及可复现检索评测；详见 `evals/qinglan/report.md`。

## 本轮补齐

前端原先固定 `top_k=3`，无法使用后端已有的召回数量参数。现在可选择 1–8 段，默认仍为 3；提问期间禁止修改。数量控制向量召回上限，相邻补充开启后总上下文仍受后端 8 段预算限制。选择更多片段可能增加无关内容与模型耗时，不保证答案一定更好。

回答旁显示后端返回的实际参考片段数及相邻补充开关状态。标准问答可以只使用 1 段来源；缓存答案沿用原答案的片段信息。旧会话没有这些字段时不显示，引用数与检索片段数分别展示。

保留原 VPN 示例并增加“统一问答需要先选择知识库吗？”固定问题，点击填入输入框，再由用户发送。

## 验证

- 后端 pytest：305 项通过；Ruff 通过。
- 前端 Node 测试：18 项通过；Vite 构建通过。
- 浏览器实际选择 5 段并发送固定问题，命中标准问答，显示“参考 1 段资料”和可核对引用。
- 本轮未调用付费生成接口，也未重新测量 RAG 答案正确率。已有青岚数据说明 Top-3 缺失的一处证据在 Top-5 找到；这只是增加选择入口的依据，不是本轮质量提升结论。
