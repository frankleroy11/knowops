# 逐事实引用校验：实现与回归

分支：`fix/citation-completeness`。本改动单独提交审查，暂不合并 main。

## 行为

原实现只验证 source_ids 范围，答案正文与引用之间没有逐事实对应关系。
新实现要求 Qwen 返回 claims，每条包含 text 和 evidence（source_id、quote）。
后端校验所有摘录出自模型实际看到的前 1200 字上下文（仅容忍空白布局差异），
从已校验的 claims 组装 answer，引用集合由 evidence 推导去重。
不接受额外自由答案字段、无依据事实、空摘录、越界编号或任一子问题未回答的肯定响应。
前端在来源展开区显示逐事实引用摘录，并保留完整切片供核对。

API 保留 answer / answerable / citations，新增 claims / grounding_status。
状态区分 no_context、model_refused、incomplete_answer、missing_claims、invalid_source、invalid_evidence、quotes_validated。
结构不合法仍返回 502，供应商不可用仍返回 503。
`quotes_validated` 只表示摘录存在于上下文，不保证其语义蕴含 text，也不保证回答覆盖全部子问题。
模型仍可能把通用规则用于特例；这是当前实现的明确边界。

## 复核与决策

NEW-01 两组补齐“不结转”的原文引用；NEW-07 两组不再混用审批时限，转为拒答；
NEW-10 重排组不再猜测邮件提醒规则。但 NEW-02 重排仍把通用耗材时限用于彩色墨盒，
且 NEW-03 普通组及最终轮 NEW-11 重排组因无效来源编号被拦截，NEW-09 普通组在证据齐全时模型拒答。
NEW-05 普通组仍有正确的 FAQ 等价证据被严格标签漏判，保持冻结标准不事后修改。

因此本轮交付的是可审查的逐事实证据校验机制，尚不能宣称整体质量提升。
保持 main 的已验证版本，PR 使用草稿状态，先处理来源编号误用和不必要拒答，再决定合并。
不通过放宽来源校验或重复生成直到成功来掩盖回归。
