# 演示开放注册、登录和多用户管理

## 注册与登录

登录页可点击“注册账号”，填写显示名、邮箱、密码与确认密码。服务端校验邮箱、密码策略和重复账号；客户端不能指定角色或租户。注册成功后返回登录，预填邮箱。登录可显示/隐藏密码，并继续支持 API Token、SSO 和 TOTP。

本机已设置 `AUTH_MODE=enforced`、`PUBLIC_REGISTRATION_ENABLED=true`。配置开关在代码中默认 false，`.env.example` 演示配置明确设为 true；关闭后前端隐藏入口，服务端拒绝注册。`GET /auth/options` 返回是否开放。

每个公开注册账号成为**新建独立演示空间的租户管理员**，不是平台管理员。不加入现有空间，不自动获得任何已有企业知识库权限。该账号可创建自己的知识库，并在自己的用户管理页添加编辑者、只读成员或其他租户管理员。平台管理员可以查看全部注册账号，按需要调整所属空间。

本项目按演示用途开放注册，**没有邮箱验证或真实邮件发送**。忘记密码页明确说明联系管理员，不再假称已发送邮件。现有账户不会被自动转成公开注册账户。

`POST /auth/register`：email、display_name、password、confirm_password；返回注册结果，不直接签发登录 Token。新租户、用户和注册审计同事务提交，邮箱竞争导致唯一键冲突会回滚新空间。沿用来源 IP 窗口限流，将注册调用记录为 registration 来源；成功登录只清理该邮箱在当前 IP 的失败记录，不清空其他用户或注册限流计数。

## 多用户管理

- 用户列表支持邮箱/显示名的字面子串搜索、角色/启用状态筛选、分页（默认 50、最多 100）。租户权限在 SQL 查询中执行。
- 创建成员可同时填写初始密码，也可以稍后设置密码或签发 Token。列表显示是否设置密码、锁定时间和未过期有效 Token 数。
- 修改角色、启停与所属空间先完成全部校验，再与审计一次提交，失败不会留下半次修改。
- 密码变化、角色/启停/空间变化会吊销旧 Token；启用账号不会恢复旧 Token。用户自行修改密码后退出并重新登录。
- 转移空间会清除旧知识库成员关系，防止再次移回时旧权限复活。
- 当前登录管理员不能自我降权、停用或转移；每个空间至少保留一个启用管理员，平台级管理员也按同一保护规则处理。并发管理操作按固定顺序锁定管理员记录。
- 成员密码设置要求重复确认；退出登录或会话失效时清除界面中的初始密码、密码弹窗和一次性 Token。

没有添加邮箱验证、邀请邮件、用户永久删除、组织加入申请或生产会话设备列表。停用/吊销可用于演示离职处理；同一浏览器配置下的多个标签页仍共用 localStorage 登录状态，演示不同用户请用独立浏览器配置或无痕窗口。

## 验收（2026-10-15，本次运行）

- 264 项后端测试、18 项前端测试、Ruff 和前端构建通过。
- 新增测试覆盖注册隔离、客户端提权拒绝、格式/密码/重复验证、注册关闭、限流不被登录抹除、账号修改原子性、密码重置吊销、用户搜索以及最后一个租户管理员保护。
- `PYTHONPATH=. python scripts/check_user_accounts.py`：实际 MySQL、真实 HTTP 路由（TestClient，无依赖替换），验证两次公开注册、密码登录、跨空间 404、平台接口 403、创建只读成员、重置密码、改角色、停用/启用、旧会话失效和搜索筛选。来源使用专用保留测试 IP，避免影响正常限流记录。
- 另用浏览器实际登录已注册的临时账号，确认只见自己的空间、用户页仅显示自己和所建成员，搜索有效；检查注册表单与成员密码弹窗。未通过浏览器提交密码修改，实际重置由上述 API 验收完成。
- UI 检查后执行 `scripts/check_user_accounts.py --cleanup`，按保存的精确 ID 清理本次账号、空间、空知识库、审计和 Token；原账号与业务库保留。暂存凭据文件权限 0600，清理时删除，不入 Git。

## 复现

在开放注册的开发配置下运行上述脚本，必要时可在清理前使用 `.tmp/account-acceptance-private.json` 中的临时账号检查界面。脚本不是普通业务操作，请勿与其他验收脚本并发运行。完成后必须执行 `--cleanup`。所有真实演示数据均限于脚本创建的空间。
