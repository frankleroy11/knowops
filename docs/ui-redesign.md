# 前端改版：去掉左侧栏、新增整页登录页与安全设置

## 1. 布局：左侧栏 → 顶栏

原来的左侧固定侧边栏（254px）承担了三件事：品牌、知识库列表、账号信息。改版后：

| 原来（左侧栏） | 现在（顶栏） |
|---|---|
| 品牌 + 副标题 | 顶栏左侧品牌 |
| 知识库列表 | **检索范围切换器**（点击展开浮层，含"统一问答"、各知识库与其权限、创建入口） |
| 底部账号与退出 | **用户菜单**（头像 + 角色；含"安全设置"与"退出登录"） |
| — | 主导航（知识问答 / 文档管理）与"用户管理""接口文档"入口 |

正文居中在 1080px 的阅读宽度内，页面标题区改成"eyebrow + 标题 + 说明"的层级。
整体是一套轻量设计系统（CSS 变量：品牌绿、墨色、行线、圆角、阴影），
按钮/输入/表格/徽标/弹层/消息气泡统一风格，并带 860px 与 620px 两档响应式收敛。

## 2. 登录页（成员与管理员同一入口）

改版前只是一个遮罩弹窗；现在是**整页登录页**：左侧品牌区（渐变 + 卖点），右侧登录卡片。

- **成员与管理员用同一个入口**，登录后按角色显示功能：管理员顶栏出现"用户管理"，
  普通成员只看到自己有权访问的知识库（浮层里标注各自权限）。
- 支持邮箱密码登录，**账号开启二次验证时自动出现验证码输入框**
  （后端返回"需要二次验证码"时前端展开该字段，不需要用户先猜）。
- 企业 SSO 按钮（仅当服务端启用 OIDC 时出现）、API Token 登录（折叠，供脚本/接口用户）。
- **忘记密码**两视图：提交邮箱 → 粘贴管理员转交的一次性令牌并设置新密码；
  本地调试模式下（`AUTH_DEV_REVEAL_RESET_TOKEN=true`）自动带出令牌。

## 3. 安全设置面板

用户菜单 → 安全设置，三块内容：

1. **修改密码**：当前密码 + 新密码（面板内提示策略：≥8 位、含字母与数字、不与最近用过的重复）。
2. **二次验证**：显示状态徽标；未开启时"开始设置"给出 base32 密钥与 `otpauth://` 链接，
   输入验证码后开启；已开启时输入验证码即可关闭。
3. **会话**：说明退出行为（吊销 Token；SSO 登录会同时结束提供方会话）与退出按钮。

**为什么不做二维码**：生成二维码需要引入依赖，或调用第三方图片服务把密钥发给外部；
两者都不合适，因此展示密钥与 otpauth 链接供认证器手动录入。

## 4. 顺带

- 审计弹层增加"导出 CSV"按钮（复用 `GET /admin/audit-logs/export`，按当前租户筛选）。
- 用户/成员表在显示名与邮箱相同时不再重复显示两行。
- 品牌字标在 flex 布局下的多余间距修掉。
