# 结构优先切分与开发对照

## 使用

默认仍是固定字符窗口：800 字符、重叠 100 字符。可在 API 的 `.env` 设置：

```env
CHUNK_STRATEGY=structure
CHUNK_SIZE=800
CHUNK_OVERLAP=100
```

修改配置后重启 API。新上传的文档/版本记录策略、大小和重叠，Worker 按版本记录解析，后续配置变化不影响该版本重试。修改 Worker 代码后必须重启 Worker。要对历史资料试新策略，请上传新版本、等待解析/索引并按权限审核；不会自动重切已解析的旧版本，也不要直接删除旧 chunks 后重跑，避免旧向量成为孤儿。

Alembic 迁移 0012 给旧版本补上 fixed / 800 / 100 标识，只增加列，不改正文、切片或向量。版本历史和文档列表 API 返回这些策略字段。本机已迁移至 0012；全局配置仍为 fixed，所有原有 232 个版本保持 fixed。

## 算法与边界

结构优先依次寻找 Markdown 标题/小块开始、段落边界、句末标点、换行；过早的边界一般不选，避免大量碎片。小型竖线 Markdown 表格和三反引号代码块在不超过窗口时优先保持完整。没有合适边界、无标点长文本或超长表格/代码块回退固定上限窗口。

输出均为清理空字符和首尾空白后的原文连续子串，不生成标题前缀、不重写表格、不调用模型做切分。块与标题边界可能不保留重叠，普通边界只保留不超过配置的重叠，硬截断才使用精确字符重叠。字符上限与 token 数不同；Embedding 仍受自身 max_length 限制。

PDF 先用 pypdf 提取文字，再逐页切分，不跨页合并且保留页码。PDF 版式、跨页表格、扫描件 OCR、语义分块、中文条款编号层级、缩进代码块、波浪号围栏和复杂 Markdown 嵌套未实现。所谓“结构优先”是规则边界选择，不是语义理解。

## 真实对照（2026-10-15）

原始结果：`evals/chunking/results.json`；脚本：`scripts/evaluate_chunking.py`。

两个强制认证 API 仅 CHUNK_STRATEGY 不同，使用同一临时租户、三份合成文档、相同 BGE-M3、Qwen-plus、top-k=3、800/100 参数。每份文档单独建库，比较为单库检索，不是统一问答大库基准。真实经过上传、Celery、MySQL、BGE-M3、Milvus 与 Qwen；共六次文档上传、十二次问答。测试先固定窗口后结构优先，仅运行一次，未做顺序随机化或显著性推断。

| 指标 | fixed | structure |
|---|---:|---:|
| 文档数 | 3 | 3 |
| 切片总数 | 5 | 5 |
| 标注证据完整落在单片的文档 | 1/3 | 3/3 |
| 启发式预期通过 | 5/6 | 6/6 |
| 有答案题输出期望关键词并带引用 | 4/5 | 5/5 |
| 资料缺失正确拒答 | 1/1 | 1/1 |

数据刻意包含窗口边界上的长审批条款、小表格和短制度，是开发回归而非独立盲测或生产正确率。单片证据完整不证明整体语义正确；关键词和引用检查也不是完整人工评分。

具体改善：固定窗口将“128 元”条件与“部门负责人批准”拆开，模型拒答；结构优先保持该长条款完整，返回金额和审批人，原文直接支持这两个事实。表格完整性提高，但固定策略本来也答对了表格题，不能把结构指标提升都算成问答收益。

此前“白鹭验收计划报销必须提交什么凭证？”曾误拒答。本轮两种策略均答对；本轮单库上下文与此前统一问答上下文不同，不能归因于新切分，也不能宣称误拒答已根治。此次没有修改 Qwen 提示或放松证据校验。

保存的真实检索内容已逐文档与策略输出核对一致。临时知识库、账号、租户、审计和上传文件清理完成，所有表记录数、存储文件集合及逻辑向量数恢复基线。原有 12 个知识库、232 份文档、759 个 SQL 切片、758 条 Milvus 向量保留。

## 验证与下一阶段

254 项后端测试通过：结构切分不丢非空白字符、连续原文、字符上限、小表格/代码块保护、无标点兜底、两种策略保留 PDF 页码；新增测试通过真实解析函数证明上传策略快照不受后续配置影响，重复任务不重切。

1. 先在业务代表性文档上补充多条款、跨页表格、长代码与中文编号样例，再做扩大/冻结评测。
2. 对误拒答做上下文与提问口径对照，验证澄清问题策略；不要用补造答案绕过证据要求。
3. 达到质量与开销目标后，另行决定是否把 structure 设为默认并迁移特定历史版本。当前不批量重建旧库。

复现：在项目根目录启动两个 API（开发实例），使用正常 Worker，然后运行评测。脚本会调用真实 Qwen，使用合成内容并清理临时数据；不要与业务写入并行执行。

```bash
AUTH_MODE=enforced CHUNK_STRATEGY=structure python -m uvicorn app.main:app --host 127.0.0.1 --port 8012

```
