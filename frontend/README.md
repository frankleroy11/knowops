# KnowOps Vue 前端

安装：`npm ci`；构建：`npm run build`。
在项目根目录启动 API 与 Worker 后，访问 http://127.0.0.1:8010/ui/ 。
首次构建后若 API 已启动，请重启 API 使静态目录挂载生效。
前端构建产物与 node_modules 不提交 Git。
开发：`npm run dev`，访问 http://127.0.0.1:5173/ui/ ，/api 代理到 8010。
页面每 5 秒刷新当前页文档状态；知识库切换后清空当前问题展示。
每轮问答独立执行，无历史对话持久化。当前本机开发空间没有用户鉴权。
